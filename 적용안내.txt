백야산장 · 조이스틱 및 그래픽 개선판

이번에 첨부한 index(4).html, sw(2).js를 기준으로 수정했습니다.

적용
1. 기존 배포 폴더의 index.html을 이 파일로 교체합니다.
2. 같은 폴더의 sw.js도 함께 교체합니다.
3. 기존 manifest.webmanifest, 아이콘과 Firebase 설정은 유지합니다.
4. 웹사이트를 새로고침합니다. 설치된 앱이 이전 화면을 보여주면 완전히 종료한 뒤 다시 실행하세요.

조작
- 왼쪽 원형 조이스틱: 누른 채 원하는 방향으로 끌어서 이동합니다.
- 손을 떼거나 중앙으로 돌리면 멈춥니다. 충돌 시 벽·가구를 통과하지 않습니다.
- 오른쪽 조사: 바라보는 물체 조사 / 대화 진행.
- 수첩: 증거, 알리바이, 층별 지도.
- PC: 방향키 또는 WASD, Space 조사, N 수첩, Esc 나가기.

수정 사항
- 네 방향 이동 버튼을 포인터 캡처 방식 원형 조이스틱으로 교체.
- 손을 떼거나 포인터가 취소되거나 창이 비활성화되면 이동 해제.
- 목재·카펫·타일 질감, 벽면 패널·창틀, 가구와 방향별 캐릭터를 개선.
- 창문의 찬 빛과 램프·벽난로의 따뜻한 빛, 주변 그림자 적용.
- 작은 화면과 가로 화면의 조작 패널 배치 개선.
- 새 그래픽이 반영되도록 서비스워커 캐시 버전 변경.

유지 사항
최신 첨부본의 Firebase 연동 코드, 역할 배정, 조사권, 선착순 증거 획득 규칙,
1·2차 개방 조건, 증거·알리바이·투표 데이터는 유지했습니다.

검증 범위
스크립트 문법, 3개 층 캔버스 렌더링, 조이스틱 방향·중앙 정지·해제·팝업 중 입력 차단,
기존 연동 코드와 데이터 보존을 검사했습니다.
실제 Firebase 서버에 접속한 다중 기기 시험과 실제 모바일 브라우저 시험은 수행하지 않았습니다.
