마지막 초대장 · 17인 Firebase 연결 수정 v21

확인된 원인
- 첨부한 17인 HTML에서 FIREBASE_CONFIG가 비어 있어 동기화가 시작되지 않았습니다.
- 전달된 Realtime Database의 읽기 요청이 Permission denied로 거부됐습니다.

1. GitHub 배포 파일 교체
index.html, sw.js, manifest.webmanifest를 기존 배포 위치에 같은 이름으로 교체합니다.
기존 아이콘 파일은 그대로 둡니다.
남가온·조은호 제외 및 17인 배정은 유지합니다.

2. Firebase 규칙 적용 (임시 테스트용)
Firebase 콘솔 > Realtime Database > 규칙으로 이동합니다.
동봉한 firebase-test-rules.json 내용을 규칙 편집기에 붙여 넣고 게시합니다.
이 JSON 파일은 게임 사이트에 업로드하는 것만으로 적용되지 않습니다.
규칙은 rooms/main 방에 한해 2026년 10월 28일 00:00(한국시간) 전까지 인증 없는 읽기·쓰기를 허용합니다.
그동안 연결 정보를 아는 사람은 해당 방 데이터를 읽거나 변경할 수 있습니다. 연결 확인용이며, 실명·민감정보를 넣지 마세요. 지속 운영에는 인증·진행자 권한 보호를 추가해야 합니다.

3. 확인
게임을 닫고 다시 열거나 새 시크릿 창에서 접속합니다.
홈 또는 진행자 화면에서 '17인 연결 수정 v21' 표시를 확인합니다.
정상 연결은 '데이터 동기화 연결됨'으로 표시됩니다.
참가자 입장 후 Firebase 데이터 탭에 rooms > main > presence 및 cast가 생기는지 확인합니다.
presence는 현재 접속 정보라 브라우저를 닫으면 사라질 수 있습니다.
진행자 단계 변경 후 stage가 생성되고 참가자에게 같은 단계가 반영되는지 확인합니다.
데이터를 콘솔에 수동으로 만들 필요는 없습니다.

오류가 남을 때
화면의 오류 문구와 실제 게임 주소를 함께 확인합니다.
권한 오류는 Firebase 규칙 게시 여부 및 App Check 적용 여부를 확인해야 합니다.

검증 범위
스크립트 문법, 17인/제외 배역, 설정 누락 수정, SDK 실패 표시를 검사했습니다.
독립된 두 실행 환경과 모의 서버로 배역 등록·진행자 단계 전달을 검사했습니다.
실제 Firebase 규칙 변경 및 휴대폰 간 연결 성공은 아직 확인하지 않았습니다.
