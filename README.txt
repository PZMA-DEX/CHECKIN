마지막 체크인 PWA v8 · 상세설정집 & 간편 UI

1) 메인 / 설정집 / 지도 / 증거목록 네 메뉴
2) 메인에 19인 표시 이름과 직업. 각 인물 선택 시 알리바이 메모와 1:1 밀담, 투표시간에만 범인 지목.
3) 지도는 증거 수집 단계에서만 접근. 종료 시 스토리북 메뉴로 전환.
4) 홍예진(15번)은 서도윤의 사실혼 연인. 남성 배정이면 피해자 여성, 여성 배정이면 피해자 남성, 기타/미지정이면 피해자 미지정. 피해자 원래 이름 서도윤 유지.
5) 배역은 성별 고정 없이 배정. 참가자 이름이 화면에 표시되며 원래 배역명은 개인 설정집에서 확인 가능.
6) 초기화는 관리자 로그인 후 관리자 콘솔에서만 표시.
7) 19인 상세설정집은 배역당 오전·오후 준비 행적과 사건 시간대 목격 정보를 포함.
8) 진범 임수빈, 확정 은폐 조력자 최민서, 조건부 김도현/배수아 규칙 유지.

[중요] 모든 비밀은 HTML 소스에 들어 있습니다. 실제 참가자에게 이 버전을 공개하면 개발자도구를 통해 진실을 볼 수 있습니다.
실전에서는 Supabase 인증·행 별 접근 제어를 적용해야 합니다. 로컬 데모의 1:1 쪽지는 다른 스마트폰에 실제 전달되지 않으며 단계·투표도 동기화되지 않습니다.
