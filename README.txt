마지막 체크인 — v9 모바일 PWA

1. 패키지 내부 파일을 모두 GitHub Pages 저장소의 같은 폴더에 업로드합니다.
2. GitHub Pages HTTPS 주소로 접속한 후 Android Chrome은 ‘앱 설치’ 또는 ‘홈 화면에 추가’, iPhone Safari는 공유 → 홈 화면에 추가를 선택합니다.
3. 최초 접속은 전용 등록 화면이며 이름과 성별을 입력한 뒤 배역을 배정받습니다.
4. 피해자는 남성 서도윤으로 고정됩니다. 홍예진(사실혼 여자친구)은 여성 참가자에게만 배정됩니다.
5. 5개 메뉴: 메인 / 설정집 / 채팅 / 지도 / 증거목록. 지도는 수집 시간에만, 투표는 관리자 단계에서만 사용합니다.
6. 증거목록에서 항목을 누르면 확대하여 상대에게 화면을 보여줄 수 있습니다.
7. 개인 채팅과 공범 연락망은 현재 한 브라우저에서만 동작하는 로컬 시연이며, 실제 휴대폰 간 공유는 Supabase 연결이 필요합니다.
8. 오직 여성 참가자만 홍예진 배역에 배정될 수 있으므로 실제 19인 전체 배정에는 여성 참가자가 최소 1명 필요합니다. 지금의 로컬 순차 무작위 배정은 역할 가용성을 보장하지 않으므로 Supabase에서는 전체 참가자 등록 후 여성을 무작위 선발하는 일괄 배정 로직으로 교체해야 합니다.
9. 관리자 로그인·비밀 접근 규칙은 클라이언트 측 데모입니다. 실제 행사 운영에는 Supabase Auth/RLS로 반드시 보호해야 합니다.
10. 사용자 확대·축소는 viewport 설정과 모바일 CSS로 제한했지만, 일부 브라우저와 접근성 설정은 이를 무시할 수 있습니다.
