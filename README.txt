백야산장 Firebase 연결 설정 적용본

1. index.html과 sw.js를 기존 배포 위치에 함께 덮어씁니다. 기존 manifest와 아이콘 등 다른 파일은 유지합니다.
2. 모든 기기에서 게임을 완전히 닫고 같은 링크로 다시 접속합니다.
3. 진행자와 참가자가 각각 접속해 배역 등록 후, 진행자의 단계 변경이 참가자에게 반영되는지 확인합니다.

Firebase 프로젝트: checkin-322ab
게임 방: main
전달된 Realtime Database 주소를 적용했습니다. 현재 로그인 없는 기존 연결 구조를 사용하므로, 데이터베이스 규칙이 이 게임의 읽기·쓰기를 허용해야 동작합니다. 인증이 필요한 규칙을 적용하려면 게임에도 인증 구현이 필요합니다.

동기화 범위는 기존 참가자 배정·단계·쪽지·투표 등이며 캐릭터 좌표 실시간 공유는 포함되지 않습니다. 실제 다중 기기 접속은 이 파일 전달 후 확인해야 합니다.
