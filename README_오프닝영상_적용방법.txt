청명산장 오프닝 영상 적용 안내 (v2 수정대본 유지)

1. index.html 및 opening_animation.mp4 두 파일을 기존 웹사이트 최상위 폴더에 함께 업로드합니다.
2. sw.js도 함께 교체해야 이전 index.html 캐시 문제를 예방할 수 있습니다.
3. 기존 manifest.webmanifest, firebase-rules.json, ending_book.html, ending_book.pdf는 그대로 유지합니다.
4. 브라우저에서 새로고침(Ctrl+Shift+R) 후 관리자 화면에서 오프닝 단계를 실행해 확인합니다.

재생 방식:
- 4분 길이 세로형 영상을 배경으로 재생합니다.
- 영상에 직접 새겨진 기존 자막은 화면 하단 가림막으로 최대한 가리고 수정 대본 v2를 위에 표시합니다.
- 참가자 배역별 1분 50초 위치 자막, 2분 2초 분기를 그대로 유지합니다.
- 원본 영상에 수정 전 대사 음성이 있을 수 있으므로 영상 소리는 기본 음소거합니다. 오프닝 화면의 '영상 음소거' 버튼으로 소리를 켤 수 있습니다.
- 4분 게임 타이머에 영상 위치를 동기화하며 중간 입장/복귀 시 현재 장면을 재생합니다.
- 영상이 로드되지 않으면 화면의 수정 대본이 남아 있습니다.

참고: video 파일은 원본 65MB에서 모바일용 720x1280 H.264로 재인코딩했습니다.
